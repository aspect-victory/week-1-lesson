# My First Web Page

A simple beginner project to practice basic HTML structure and elements.

## Description
This project contains a single HTML file that displays a "Hello, World!" message, a brief paragraph, and a link to external resources. It serves as a boilerplate for learning how web pages are structured.

## Technologies Used
* HTML5

## How to Run
1. Download or clone this repository.
2. Locate the `index.html` file in your folder.
3. Double-click the file to open it in your default web browser (Chrome, Firefox, Safari, etc.).

## Features
- Main heading using `<h1>`
- Descriptive paragraph using `<p>`
- External hyperlink using `<a>`
